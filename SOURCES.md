# Sources

This add-on is our own project. This file records where details came from,
so findings and fixes can be sent back to those projects.

| Source | What we used | Licence | Send back |
|---|---|---|---|

Shipped from Bosch: the fault table (`app/faults.json`) carries Bosch's
titles, descriptions and measures for each fault code, so the page can say
what a message means and what to do. Not shipped: descriptor files or any app
binaries. The datapoint table carries only IDs, names and type information.
